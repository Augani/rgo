# rgo dogfood measurements — macOS 15 (APFS), Cargo 1.98, 2026-09-18

Fixture: workspace {app, cli, bench} bins + {shared} lib; deps serde, serde_json,
tokio(full), rand, anyhow — ~60 crates.

| Scenario | Checkout target/ | Managed builds/ |
|---|---|---|
| Plain cargo (no rgo) | 194.3 MiB, 702 files | — |
| rgo managed, `cargo build` | 8.7 MiB, 11 files | 181.2 MiB |
| + no-op + touch rebuild + `--release` | 11.1 MiB | 300.9 MiB |
| + 2nd checkout (worktree copy) | 11.1 MiB each | 482.1 MiB (2 contexts) |
| delete 2nd checkout -> orphan -> `rgo gc --aggressive` | — | 300.9 MiB (reclaimed 181.2) |
| cross-volume (APFS image, release) | 11.1 MiB | 117.2 MiB |

Verified:
- Checkout retains ONLY uplifted final outputs (bins + .d); intermediates centralized.
- `rgo ls` attribution via wrapper sidecars; orphan detection on manifest deletion.
- GC never removed a context younger than the 10-min live window; orphan reclaimed after aging.
- Cross-volume: Cargo copies (not hardlinks) uplifted bins — target binary is a real
  copy on the checkout volume (different dev+ino, nlink=1). Trade-off: same-volume
  hardlink = ~0 extra checkout bytes; cross-volume = binary-size copy per target.
